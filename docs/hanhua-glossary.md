# 漢化術語對照表(繁體中文)

這份是漢化的**唯一術語標準**。翻譯時一律照這裡的用詞,確保全站一致。

> 原則:**玩家熟悉度優先**。官方繁中用語與社群慣用不同時,採社群慣用,並在備註標明。

## 現在字典住在哪裡(2026-09-07 起)

漢化不再寫死在原始碼裡,改走上游 `Moris-kr/nikke-calc` 的語言層(`site/src/i18n.ts`)。
**原始碼一律寫韓文**,畫面由 `watchLocalize()` 的 MutationObserver 逐一換成當前語言。

| | |
|---|---|
| 字典正本 | `site/src/locale/zh-tw.ts` —— **與上游逐字元相同,不要手改** |
| 本 fork 的覆蓋 | `site/src/locale/zh-tw.fork.ts` —— 只放與上游不同、或上游沒有的條目 |
| 角色・技能・魔方・珍藏品名稱 | `data/locale_text.json`(遊戲官方 CDN,`scraper/cdn_locale.py` 取得) |

同步上游時:`git checkout upstream/master -- site/src/locale/zh-tw.ts` 一行即可,
本 fork 的用語決策不會被沖掉。**要改用詞就改 `zh-tw.fork.ts`,不要改 `zh-tw.ts`。**

值與文字混排的句子(`第 3 名 · 對比第 1 名 4.2%`)DOM 觀察器翻不了 ——
那種要寫成 `t('{n}위 · 1위 대비 {gap}%', { n, gap })`,並確保字典有那個韓文鍵。
同理,`${…}` 兩側的文字在畫面上會**併成同一個文字節點**,字典要收「併起來的樣子」。

**更新公告已移除**(2026-09-07)。`notices.ts` 是上游衝突最頻繁的檔案(每支功能 commit
都往頂端加一條),而且上游的公告有一半在講本 fork 沒有的功能。整個功能拿掉了 ——
往後同步時 `notices.ts` 直接當 DU 丟棄。
