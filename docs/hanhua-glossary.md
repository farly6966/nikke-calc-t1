  「推薦操作」句子裡,翻了會中韓混雜,需連同那些句子一起改。暫留韓文。
- **戰鬥摘要行**(180초 · 무속성 · 코어 없음 · 기대값 等動態字):待處理。
- **角色名**(L2):打算抓 CDN 官方中文,不手動翻。

## 不可翻譯(資料鍵 / 內部值,翻了會壞)

- 裝備部位鍵:`머리 / 몸통 / 팔 / 다리`
- 角色名在引擎資料(`parsed_nikke.json` 等)中的韓文 key
