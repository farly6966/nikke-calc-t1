# 유니온 레이드 보스 카드

명단 정본은 `site/src/data/union-seasons.json`이며 `site/src/union-bosses.ts`가
회차별 이름, 적 속성, 약점, 이미지 식별자를 해석한다.
추천 전투 조건의 정본은 `site/src/data/union-s44-recommendation.json`이다.
날짜가 지나도 최신 회차라고 자동 표시하지 않고 실제 회차와 시작일을 표시한다.

## 회차 명단 (2026-09-12 확인)

- DILDORO 공개 `app.js?v=823cbf7c`의 `UNION_SEASONS`: S35~S44, 각 5보스.
- 원본 배열의 게임 내 등장 순서를 유지한다. 속성별로 재정렬하지 않는다.
- 날짜·이름·속성·그림 키를 JSON에 고정하고, `i18n/en.js`, `i18n/ja.js`,
  `i18n/zh.js`에서 해당 이름의 번역만 함께 보관한다. fork 사전이 우선한다.
- S36·S39·S42의 크라켄 그림 `bbg004_dmtr_intercept.webp`는 원본 서버도 404다.
  다른 보스 그림을 대신 쓰지 않고 이름으로 표시한다. 나머지 31종의 그림은 로컬에 보관한다.

## 전투 조건

회차 드롭다운을 바꾸면 **보스 1~5가 즉시 채워진다**. 별도 적용 버튼과 6번 칸은 없다.
새 빈 판은 S44로 시작하지만, 기존 사용자 설정이나 불러온 판은 자동 덮어쓰지 않는다.
위 그림 다섯 개는 해당 편집기로 이동하기만 하며 설정과 계산 결과를 바꾸지 않는다.
각 칸의 편성·버스트 설정은 유지하며 이전 판으로 되돌릴 수 있다.

S35~S43은 명단·속성만 검증됐다. 선택 시 전투 조건을 엔진 기본값으로 초기화하고
화면에 미검증 안내를 표시한다. 같은 속성이라는 이유로 S44의 방어·코어·부위·구간을
가져오지 않는다. 역사적 전투 재현에는 사용자가 해당 단계의 실제 조건을 넣어야 한다.

추천값은 2026-09-09의 DILDORO `/api/boss/rec` 응답(코드 `nu8p4v`,
회차 `1000044`)을 고정한 것이다. 공식 확정값이 아닌 커뮤니티 추천값이며
단계·실제 부위 파괴 시각에 따라 조정해야 한다. 런타임에 타 사이트 서버를 호출하지 않는다.

- 방어·코어·적정거리·무기 계수·버스트 단계 전환 간격을 그대로 반영한다.
- 단계 간격은 0.1초, 추가 반응 시간은 0초다. 원본의 단계 간격을 이 엔진의
  반응 시간으로 중복 적용하지 않는다. 추천을 쓰지 않는 기존 설정의 기본값은 유지한다.
- 첫 버스트 3초·재진입 0.5초·횟수 제한 없음은 엔진 기본값과 동일하며 테스트가 확인한다.
- `parts` 구간은 부위 피해 판정을 켜고 종료 시 부위별 파괴 이벤트를 낸다.
  겹치는 구간은 보너스를 중첩하지 않지만 중복된 종료 시각은 각각의 파괴로 센다.
- `immune`은 모든 피해를 막는다. 기존 평타만 빗나가는 `immuneWindows`와 구분한다.
- `element_gate`는 그 보스 코드에 우월한 공격만 통과한다.
- 이 구간들의 무적 중에도 장전·버스트·버프는 계속 진행한다.

그림은 식별용이며 Boss Maker의 충돌 판정용 도형이 아니다.
계산기는 각기 유지된 엔진을 쓰므로 DILDORO와 최종 피해가 동일하다고 보장하지 않는다.
기존 엔진의 기본 결과는 29개 snapshot으로 별도 검증한다.

NK4 v1은 보스 id와 긴 전투 조건을 담는다. 기존 v0 코드는 계속 읽으며,
새 형식은 이 기능이 반영된 계산기에서 열어야 한다.

## 6칸에서 5칸으로 이전

- 새 저장소는 `nikke-union-board-v2`다. 기존 `nikke-union-board-v1`은 수정하지 않는다.
- v2가 없거나 깨졌으면 v1의 앞 다섯 칸을 복원한다. 6번 칸은 계산·검색·새 공유에서 제외한다.
- 화면의 접힌 백업 영역에서 옛 6번 칸을 선택한 1~5번 칸으로 복사할 수 있다.
  덮어쓰기를 명시하며, 복원 취소는 이전 조건과 편성을 함께 되살린다.
- 옛 6칸 NK4를 불러오면 원본 코드는 `nikke-union-retired-shares-v1`에 별도로 보관한다.
  새로고침 후에도 6번 칸을 복구할 수 있다. 같은 코드는 중복 보관하지 않는다.
- 일반 회차 변경 취소는 이후에 수정한 편성을 유지한다. 저장한 회차는 보스 id로 추론하며
  다시 열 때 수동 전투 조건을 추천값으로 초기화하지 않는다.

## 갱신

새 회차를 JSON에 추가하고 이름·적 코드·약점을 대조한다. 그림을 확인한 뒤 위 출처에
기록한다. 한국어 원문과 공개 번역을 쓰며 필요하면 en/ja/zh-tw.fork 사전에서 보정한다.
기존 id는 바꾸지 않는다. 저장한 판과 NK4 공유가 이 id로 그림을 복원한다.
회차를 적용해도 기존 편성을 지우지 않으며, 적용 직후 이전 판으로 되돌릴 수 있다.
