# 聯盟突襲同隊比較 — 使用說明

把公會成員各自匯出的 JSON 讀進來，**用同一套隊伍、同一個王**跑一次，看誰能貢獻多少。

> **這個工具跑在你自己的電腦上，不在網站上。**
> 資料一步都不會離開你的電腦，也不會上傳到任何地方。
> 網站（<https://farly6966.github.io/nikke-calc-t1/>）是另一個東西 —— 那是計算機本身。

---

## 一次性準備（約 10 分鐘）

### 1. 安裝 Python

<https://www.python.org/downloads/>

**Windows 使用者注意**：安裝畫面最下面有一個 `Add python.exe to PATH` 的勾選框，
**一定要勾**。沒勾的話後面按兩下會閃一下就關掉，而且看不到任何錯誤訊息。
忘記勾了就重跑一次安裝程式，選 `Modify` 補勾。

不需要 `pip install` 任何東西 —— 這兩支腳本只用 Python 內建的功能。

### 2. 下載程式

到 <https://github.com/farly6966/nikke-calc-t1> →
綠色 **`Code`** 按鈕 → **`Download ZIP`** → 解壓縮到桌面。

不需要 git、不需要 Node.js、不需要 npm。

---

## 每次使用（約 1 分鐘）

### 3. 放檔案

把成員的 JSON 檔全部丟進資料夾裡的 **`exports/`**。
沒有這個資料夾就自己建一個（或先執行一次第 5 步，程式會自動建好）。

檔名隨便取，程式讀的是檔案裡的 `name` 欄位。

### 4. 設定隊伍

用記事本（Windows）或文字編輯（Mac）打開 **`run-union.command`**（Mac）
或 **`run-union.bat`**（Windows），改最上面那幾行：

```
SQUAD="Rapi: Red Hood,Crown,Liter,Alice,Naga"
DURATION=90
ENEMY_CODE=""
```

| 設定 | 說明 |
|---|---|
| `SQUAD` | 五個角色，用逗號分隔。**英文名、韓文正式名、社群別名都可以** |
| `DURATION` | 戰鬥秒數。聯盟突襲通常是 90 |
| `ENEMY_CODE` | 王的屬性。留空 = 無屬性。可填 `풍압`／`수냉`／`작열`／`전격`／`철갑` |

角色名這幾種寫法都通，大小寫、空格、冒號都不影響：

```
Rapi: Red Hood      rapi red hood      RAPIREDHOOD
라피 : 레드 후드       라피:레드후드         흑련（社群別名）
```

打錯的話程式**不會硬跑**，它會告訴你最接近的幾個名字讓你挑。

### 5. 執行

按兩下 `run-union.command`（Mac）或 `run-union.bat`（Windows）。

排名表會自動在瀏覽器裡打開。

---

## 兩個作業系統各自的坑

### Mac：第一次按兩下會被系統擋下來

會跳出「**無法打開，因為它來自未識別的開發者**」。這是 macOS 對所有從網路下載的
檔案的預設保護。

**解法**：在 `run-union.command` 上**按右鍵 → 打開 → 再按一次「打開」**。
只需要做這一次，之後按兩下就正常。

如果按兩下完全沒反應（連視窗都沒跳），是執行權限在解壓縮時掉了。開「終端機」貼上：

```bash
chmod +x ~/Desktop/nikke-calc-t1-master/run-union.command
```

（路徑換成你實際解壓縮的位置）

### Windows：視窗閃一下就關掉

99% 是安裝 Python 時**沒勾 `Add python.exe to PATH`**。
重跑安裝程式選 `Modify` 補勾，或重裝一次記得勾。

想看到錯誤訊息的話：開「命令提示字元」，把 `run-union.bat` 拖進去按 Enter，
視窗就不會自己關掉。

## 看懂報告

| 欄位 | 意思 |
|---|---|
| 總傷害 | 這個人用這套隊、這個王能打出的傷害 |
| 對第一名 | 跟排第一的人相比的百分比 |
| 備註 | **這一列的數字有多可信** |

備註欄可能出現：

- **`추정: 호감도·장비 강화`** — 匯出檔裡沒有好感度或裝備強化階段，用了預設值。
  影響大約 1～2%，相對排名幾乎不受影響。匯出工具補上那些欄位之後這行會自己消失。
- **`미보유 N명을 기본 스펙으로 대체`** — 這個人沒有隊伍裡的某幾個角色，
  那幾個用基本規格代算。**這種人實際上打不了這套隊**，數字只能當參考。

## 進階：直接下指令

按兩下的檔案只是包裝，底下是這兩行：

```bash
python3 scraper/profile_import.py exports/
python3 -m context.union_compare --squad "Rapi: Red Hood,Crown,Liter,Alice,Naga" \
        --duration 90 --enemy-code 전격 --html out/report.html
```

常用選項：

| 選項 | 說明 |
|---|---|
| `--profiles A,B,C` | 只跑指定的幾個人（預設跑 `profiles/` 全部） |
| `--enemy-def N` | 王的防禦力。**不給的話用計算機預設 31,784，給 0 是「無防禦」** |
| `--core-px N` | 核心大小。不給就是沒有核心 |
| `--parts` | 有零件的王 |
| `--json 路徑` | 把原始數據存成 JSON，方便自己再加工 |

## 資料安全

- **`exports/`、`profiles/`、`out/` 都不會進版控。** 這個 repo 是公開的，
  提交等於發布到網際網路上。
- 匯出檔裡可能包含 cookie。
  **轉換程式完全不讀它**，也不會寫進產出的檔案，但原始的匯出檔本身還是敏感資料，不要丟到公開的地方。
